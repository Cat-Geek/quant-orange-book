# 第二篇 · 筑基篇：动手前的地基

> **本篇导读**——从这一篇开始动手。目标是：用**最小的技能集**跑通完整的回测流程，顺便避开新手死亡率最高的那些坑。
>
> 不要求你成为程序员，也不要求你啃完高数。这一篇的信条是"**够用即可，边用边学**"。

## 本篇解决什么问题

- Python 那么大，我到底要学多少？（第 6 章：答案是 20%）
- 行情数据从哪来，免费的靠谱吗？（第 7 章）
- 怎么跑出我人生第一个真实的回测？（第 8 章）
- 回测报告上那一堆数字，怎么用人话理解？（第 9 章）
- 别人踩过的坑，我怎么提前全躲开？（第 10 章 ⭐ 全书王牌）

## 怎么读

第 6-9 章是连续剧，建议按顺序；第 10 章是全书最重要的一章，配交互演示，读完请把附录 C 的自查清单打印出来。

::: tip 💡 本篇产出
读完本篇你手里会有：一套能跑的 Python 环境、你人生第一个回测、一份看得懂回测报告的眼睛、和一张八大坑自查清单。
:::
