## 案例档案

| 项 | 内容 |
|---|---|
| 家族 | 规模因子 |
| 标的 | 全市场市值最小的 N 只（剔除 ST/次新） |
| 核心逻辑 | 定期轮动持有小市值股票 |
| 赚什么钱 | 小盘溢价、壳价值、散户博弈结构 |
| 什么行情会死 | 小盘股踩踏（如 2024 年初微盘股流动性危机）、注册制壳价值衰减 |
