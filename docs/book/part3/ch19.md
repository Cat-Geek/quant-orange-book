## 小节骨架（写作大纲）

1. **AI 在策略开发中的正确岗位**：初级程序员 + 讲解员 + 陪练，**不是基金经理**
2. **工作流总览**：想法 → 人写策略逻辑说明书 → AI 转代码 → 机器体检 → 人工复核
3. **"策略逻辑说明书"写法**：让 AI 不猜的关键——标的、信号、仓位、成本、边界条件全写死
4. **实战演示**：一个想法从 prompt 到可回测代码的完整过程（含失败迭代）
5. **能力边界**：哪些环节 AI 靠谱（样板代码/指标计算/报错排查），哪些环节必须人来（逻辑审题/过拟合直觉/常识判断）

::: warning ⚠️ 本书的铁律
AI 生成的每一行策略代码，在通过 [第 20 章](/book/part3/ch20) 的验货流程之前，一律视为"嫌疑代码"。**生成 ≠ 完成，验完 ≠ 完成，理解了才算完成。**
:::
