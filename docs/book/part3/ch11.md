1. **五大家族总览**（一张地图）：趋势跟踪、轮动、多因子选股、套利配对、择时信号
2. **每个家族的"钱从哪来"**：趋势赚延续性、轮动赚强弱切换、多因子赚截面定价偏差……
3. **每个家族的"死法"**：趋势死于震荡、轮动死于同涨同跌、套利死于极端行情
4. **难度与资金阶梯**：新手从哪个家族入手最不容易死
5. **后续案例章的导览**：本书 8 个案例分别属于哪个家族
