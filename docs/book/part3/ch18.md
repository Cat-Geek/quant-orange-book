## 小节骨架（写作大纲）

1. **择时的本质**：不是为了买在最低，是为了不在巨浪里满仓
2. **经典择时信号教学版**：均线 regime（牛熊分界）、动量过滤、波动率过滤
3. **仓位管理三式**：等权、波动率倒数加权、风险预算
4. **牛熊进度条**：把市场温度做成一个可视化仪表的教学思路
5. **择时的代价**：错过大反弹的机会成本（诚实的账本）

::: tip 💡 人话翻译
择时策略的目标不是"每次都对"，而是**在最重要的时候别站错队**——熊市别满仓，比牛市买在最低重要一百倍。
:::
