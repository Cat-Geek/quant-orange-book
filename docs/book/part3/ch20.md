## 20.1 AI 量化代码的四类高发幻觉

| 幻觉类型 | 症状 | 案例 |
|---|---|---|
| 📅 时序幻觉 | 信号偷看未来（未来函数） | 忘了 `shift(1)`；用当日收盘算当日信号 |
| 📚 API 幻觉 | 调用不存在的函数/参数 | 编造 `get_price_v2()`、参数名张冠李戴 |
| 📉 数据幻觉 | 编造历史行情、虚构统计规律 | "该策略在 2015 年股灾中逆势上涨 40%"（查无此事） |
| 🧮 逻辑幻觉 | 代码能跑但逻辑≠你的想法 | 你说"突破 20 日高点买入"，它写成了"高于 20 日均线" |

## 20.2 三道验货关卡

**第一关：机器检查（自动）**
- 静态扫描：未来函数模式（信号未 shift、用了 `shift(-n)`）、除零、空值传播
- API 核对：每个函数调用对照平台文档（让 AI 自己对照也行，但要抽查）
- 成本假设：手续费/滑点设了没有

**第二关：数据检查（半自动）**
- 分年度收益拆解：是不是只赚了某一段？
- 参数敏感性：动一个参数结果剧变 = 过拟合警报
- 与基准对比：跑不赢"一直拿着"，图什么？

**第三关：人工审查（必须人做）**
- 逐行讲给自己听：AI 能跑 ≠ 你能懂
- 逻辑对照"策略逻辑说明书"：它写的是你想的吗？
- 常识拷问：这个策略赚的钱，是谁亏的？对手盘理性吗？

::: tip 💡 人话翻译
验货流程的本质：**机器管重复，数据管诚实，人管常识。** 三关全过，才配叫"完成"。
:::
