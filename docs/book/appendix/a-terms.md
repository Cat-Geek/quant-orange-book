# 附录 A · 量化术语速查表（人话版）

> 按拼音/字母排序，持续补充。看不懂的术语，随时用第 21 章的 AI 私教提问法深挖。

## A-C

| 术语 | 人话解释 |
|---|---|
| Alpha（α） | 超过大盘的那部分收益——真本事的部分 |
| Backtest 回测 | 把策略放到历史数据上"假装交易"一遍，看成绩 |
| Beta（β） | 跟着大盘一起涨跌的部分——随大流的部分 |
| 最大回撤 Max Drawdown | 净值从最高点跌下来最惨的那一刀深度 |
| 夏普比率 Sharpe | 每承担一份波动，换来多少收益。>1 及格，>2 优秀 |
| 幸存者偏差 | 只统计"活下来"的样本导致的乐观错觉 |

## F-P

| 术语 | 人话解释 |
|---|---|
| 因子 Factor | 一个"打分维度"：估值、动量、波动率…… |
| 未来函数 Look-ahead Bias | 算信号时偷看了"当时不可能知道的数据"——回测造假第一原理 |
| 过拟合 Overfitting | 把历史噪声背下来了，不是规律——历史满分，实盘垫底 |
| 前复权 / 后复权 | 把分红除权造成的价格跳空修正掉，否则收益率全是假的 |
| 滑点 Slippage | 你想 10 块买，实际成交 10.01——市场的"办事费" |
| 换手率 Turnover | 策略倒手的频率，越高摩擦成本越吃收益 |

## Q-Z

| 术语 | 人话解释 |
|---|---|
| 样本外验证 Out-of-sample | 用"没参与调参"的历史数据再考一次——防过拟合的疫苗 |
| 胜率 Win Rate | 赚钱交易占全部交易的比例（高胜率 ≠ 赚钱，见盈亏比） |
| 盈亏比 | 平均每笔赚的钱 ÷ 平均每笔亏的钱 |
| IC / IR | 因子预测能力的体检指标（第 15 章展开） |
| 拥挤交易 Crowded Trade | 大家都挤同一策略，alpha 被挤没了 |
| 处置效应 | 赚的拿不住、亏的扛到底——人类的通病 |
