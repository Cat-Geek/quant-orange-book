# 附录 C · 避坑自查清单（可打印版）

> 第 10 章（八大坑）与第 20/24 章（AI 验货）的清单合集。**每个策略上线回测前，从头过一遍。**

## 一、策略回测八查（源自第 10 章）

- [ ] **未来函数**：算信号的每一根数据，在决策时刻都发生了吗？（`shift` 了吗？）
- [ ] **过拟合**：参数做过敏感性测试吗？留样本外数据了吗？
- [ ] **幸存者偏差**：股票池含退市/ST 股吗？
- [ ] **偷价成交**：成交价假设现实吗（收盘信号次日成交）？
- [ ] **滑点手续费**：佣金、印花税、滑点都设了吗？
- [ ] **数据乌龙**：复权处理了吗？缺口和异常值检查了吗？
- [ ] **样本外失灵**：分年度收益拆过吗？牛/熊/震荡分别表现如何？
- [ ] **心态预案**：执行纪律写下来了吗？回撤多少必须停下来 review？

## 二、AI 生成代码三道关卡（源自第 20 章）

### 第一关 · 机器检查
- [ ] 静态扫描：未 shift 的信号、`shift(-n)` 用法、除零、空值
- [ ] API 核对：每个函数都在平台文档里真实存在
- [ ] 成本假设已设置且合理

### 第二关 · 数据检查
- [ ] 分年度收益拆解，不是只赚一段
- [ ] 参数动一动，结果不剧变
- [ ] 与买入持有基准对比过

### 第三关 · 人工审查
- [ ] 每一行都能讲给自己听
- [ ] 与策略逻辑说明书逐条对照
- [ ] 回答得了"这钱是谁亏的"

## 三、AI 幻觉速查（源自第 20/24 章）

- [ ] 📅 时序幻觉：信号时点检查过
- [ ] 📚 API 幻觉：函数名对照文档抽查过
- [ ] 📉 数据幻觉：AI 给的"历史战绩"用真实数据复核过
- [ ] 🧮 逻辑幻觉：代码行为与策略说明书一致
