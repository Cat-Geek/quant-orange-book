## 小节骨架（写作大纲）

1. **三个私教岗位**：概念讲解员（费曼式提问法）、代码讲解员（逐行人话注释）、苏格拉底陪练（让 AI 反过来考你）
2. **学习工作流**：读书卡壳 → 提问模板 → 追问链 → 自测闭环
3. **能力边界地图**：放心交（解释概念/解释代码/出练习题）、抽查着交（写代码/翻译研报）、必须人来（投资决策/风险判断/常识拷问）
4. **幻觉高发区预警**：具体数字、平台 API 细节、最新规则——AI 最容易一本正经胡说的三类内容
5. **提问模板**：3 个拿来即用的"量化私教"prompt 骨架
