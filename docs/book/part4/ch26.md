## 小节骨架（写作大纲）

1. **策略会死，系统长存**：任何策略都有生命周期，可迭代的工作流才是资产
2. **失效的早期信号**：连续偏离历史统计特征、市场结构变化（规则/参与者）、逻辑前提消失
3. **迭代节奏**：什么时候该忍（回撤）、什么时候该改（失效）、什么时候该扔（逻辑死了）
4. **信息源管理**：信源分级——一手（规则/数据/代码）＞二手（研报/书）＞三手（群聊/口号）
5. **AI 时代的更新压力**：工具半年一换代，但验证纪律十年不变

::: tip 💡 人话翻译
市场一直在变，但"诚实验证"这四个字不会变。**迭代的是策略，不变的是流程。**
:::
