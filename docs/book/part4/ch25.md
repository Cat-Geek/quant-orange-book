## 小节骨架（写作大纲）

1. **收藏 ≠ 知识管理**：能再次用起来才是（信息 → 笔记 → 素材 → 武器的四步链）
2. **AI 整理流水线**：研报/长文 → 核心观点提炼 → 归档打标 → 双链互联
3. **策略知识的三层结构**：想法层（灵感）/ 证据层（数据与回测）/ 结论层（可用/不可用及原因）
4. **定期复盘机制**：周记与月记的 AI 辅助模板
5. **工具选型**：Obsidian 类本地库 + AI 助手的组合拳

::: tip 💡 人话翻译
量化投资者的差距，三年后不在策略上，在**谁的知识能复利**上。收藏夹是知识的坟场，结构化笔记才是知识的复利账户。
:::
