## 模板总览（写作中逐个展开）

| 环节 | 模板 | 一句话说明 |
|---|---|---|
| 想法澄清 | T-01 想法体检 | 让 AI 拷问你的策略想法有没有逻辑漏洞 |
| 逻辑编写 | T-02 策略说明书 | 生成机器可执行的"策略逻辑说明书" |
| 代码生成 | T-03 代码翻译 | 说明书 → 平台代码，附逐行人话注释 |
| 代码审查 | T-04 自检清单执行 | 让 AI 按第 10/20 章清单自查它的代码 |
| 回测分析 | T-05 报告人话化 | 回测报告 → 人话诊断书 |
| 改进迭代 | T-06 单变量改进 | 一次只改一个变量的受控迭代 |

::: tip 💡 提示词的核心心法
不是咒语越玄乎越好，而是**上下文给足、输出格式定死、验收标准前置**。好模板 = 好岗位说明书。
:::
