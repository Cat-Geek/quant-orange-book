# 第一篇 · 认知篇：先搞懂游戏规则

> **本篇导读**——这一篇一行代码都没有，但它决定了你后面所有的路走得顺不顺。
>
> 大多数人学量化的路径是反的：先下载软件、先抄代码、先亏钱，最后才想起来问"量化到底是什么"。这一篇把顺序摆正。

## 本篇解决什么问题

- 我在市场里亏的钱，到底是运气差还是方法错？（第 1 章）
- "量化"这两个字到底指什么，能做什么、不能做什么？（第 2 章）
- 2026 年了，AI 改变了什么，学法要怎么变？（第 3 章）
- 我该怎么安排自己的学习路线？（第 4 章）
- 哪些事现在就不能做？（第 5 章）

## 怎么读

按顺序读，每章 15-25 分钟。读的时候准备一个备忘录，记下你自己的答案——这一篇的每章末尾都有"灵魂拷问"，答不上来就慢一点。
