## 小节骨架（写作大纲）

1. **把"我觉得"变成"数据说"**——量化的本质定义：想法 → 规则 → 验证 → 执行
2. **量化能做什么**：克服情绪、批量验证、风险可算、精力解放
3. **量化不能做什么**：不能预测黑天鹅、不能把垃圾想法变成赚钱策略、不能替代认知
4. **量化的门槛错觉**：门槛不在代码，在"诚实地面对数据"
5. **常见误解澄清**：量化 ≠ 高频、量化 ≠ AI、量化 ≠ 稳赚
