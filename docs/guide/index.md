# 阅读指南：三条路线，对号入座

> 这本书不用从头读到尾。找到你的路线，跳着读。

## 🐣 路线一：零基础入门（推荐大多数人）

**适合**：不会编程、被主观交易伤过、听说量化想试试的你
**节奏**：每天 30 分钟，约 6 周读完

```
第 0 步热身（今天，5 分钟）
  → 第一篇 · 认知篇 CH1-5（第 1 周）
  → 第二篇 · 筑基篇 CH6-10（第 2-4 周，边读边做）
  → 第三篇 · 挑 1-2 个案例精读（第 5-6 周）
  → 第四篇 · AI 协作篇（按需穿插）
```

::: warning 🚨 路线军规
边读边做，每章至少留下一个产物：一段代码、一份清单或一条笔记。只看不练 = 白读。
:::

## 👨‍💻 路线二：会编程的快线

**适合**：程序员 / 数据分析师，想给量化+AI 开第二曲线
**节奏**：8-10 周

```
跳过 CH6（Python 你会）
  → CH1-5 快读（重点 CH3/CH5：AI 新姿势 + 红线）
  → CH7-9 当字典查，CH10 必读 ⭐（语言都会，坑不认识照样死）
  → 第三篇按兴趣跳读 + CH19-20 必读
  → 第四篇整篇是你的主场
```

## 🤖 路线三：AI 玩家专线

**适合**：天天玩 DeepSeek/Claude，但不懂量化，想知道 AI 在投资上的能与不能
**节奏**：3 周

```
CH1-2（补市场常识，快读）
  → CH10 八大坑 ⭐（AI 生成代码的重灾区，必读）
  → CH20 验货指南 ⭐
  → 第四篇全部（你的主场：CH21-27）
  → 案例篇按需回补
```

## 通用建议（三条路线都适用）

1. **别在第一章停留太久**——认知篇是开胃菜，动手才是正餐
2. **卡壳就问 AI**——用第 21 章的私教模板，别自己硬憋
3. **每章留下产物**——这本书的设计就是让你"读完成一套系统"
