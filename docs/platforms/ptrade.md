## 1. Ptrade 是什么，适合谁

**Ptrade 是恒生电子开发的量化终端，由合作券商提供给客户使用**。定位和 QMT 类似——本地终端、可回测可（远期）实盘——但上手体感更轻：

- 策略 API 风格与聚宽相近（`initialize` / `handle_data` / `get_history` 这套命名），**写过聚宽的人迁移成本很低**
- 界面化程度高，策略管理直观

**适合谁**：你的券商给的是 Ptrade 而不是 QMT（两家是竞争关系，券商二选一居多）→ 那就用 Ptrade，学习效果等价。**没有"哪个更好"的执念，只有"你开的是哪个"的现实。**

## 2. 开通动线

1. **确认券商**：Ptrade 由支持它的券商提供，开通条件各家不同——先读[第 5 章 · 红线](/book/part1/ch5)
2. **申请权限**：客户经理处申请 Ptrade，获取下载渠道
3. **安装登录**：Windows 安装 → 券商账号登录 → 找到"策略研究 / 回测"模块
4. **新建第一个策略**：从模板或空白开始，把下面的骨架贴进去体会

## 3. 策略骨架长什么样

Ptrade 的策略骨架和聚宽神似（命名有差异）：

```python
def initialize(context):
    # 初始化：只跑一次，布置全局
    g.security = '600570.SS'        # 恒生电子（注意后缀风格）
    set_benchmark('000300.SS')       # 基准

def handle_data(context):
    # 主逻辑：按周期反复执行
    price = get_history(5, '1d', 'close', [g.security])
    ma5 = price[g.security].mean()
    log.info('MA5 = %s' % ma5)
```

> ⚠️ 上图为**结构示意**，展示"初始化 + 周期执行 + 取历史数据"三件套的形态；具体函数名与参数以你终端内置的官方文档为准——**不同券商版本的 Ptrade 细节有差异**，这本身就是本页最大的坑位（见下）。

::: tip 💡 为什么说"眼熟"
`initialize` + 周期回调 + `get_history`（取历史）+ `set_benchmark`（基准）——和聚宽同一套设计语言。学透了聚宽，Ptrade 只是"换个方言"。
:::

## 4. 两个高频错位

::: warning ⚠️ 坑位 1：文档是"你的券商版"
Ptrade 存在多个券商定制版本，**函数细节可能不同**。网上教程（包括本书）只能当"形参考"——动手前，先打开你终端里自带的 API 文档，把函数名对一遍。这正是[第 20 章](/book/part3/ch20)"API 幻觉"的现实版：教程没错，你的版本不同。
:::

::: warning ⚠️ 坑位 2：股票代码后缀又一变
聚宽 `.XSHE/.XSHG`、QMT `.SZ/.SH`、Ptrade 常见 `.SS/.SZ` 风格——**三个平台三套后缀**。抄代码不改后缀，轻则报错，重则查无此票。把"改后缀"写进你的抄代码 checklist（附录 C）。
:::

## 5. 你现在需要它吗？

::: tip 💡 诚实的建议
同 QMT：筑基阶段用聚宽足够。Ptrade 的价值在"你的券商只给它"的场景，以及远期的本地化进阶。**学习期多一个平台 = 多一份平台细节负担，而不是多一份知识。**
:::
