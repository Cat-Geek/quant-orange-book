# 平台手册：选对你的第一站

> 🎯 **这一板块的承诺**：看完一个平台页，你就能在那个平台上完成「注册 → 装好 → 跑通第一个回测」。不贩卖焦虑，只给动线。

## 三分钟选型

::: tip 💡 一句话决策
**怕麻烦、想立刻动手** → 聚宽（在线平台，浏览器里写代码跑回测，零安装）
**想要本地环境、为以后实盘铺路** → QMT / Ptrade（本地终端，需在支持券商开通）
:::

| | 聚宽 JoinQuant | QMT（迅投） | Ptrade（恒生） |
|---|---|---|---|
| **形态** | 在线平台，浏览器即用 | 本地客户端（Windows） | 券商提供的本地/界面化终端 |
| **怎么获得** | 官网注册即用 | 指定券商开通（常附资金/申请门槛） | 指定券商开通 |
| **编程语言** | Python（内置环境） | Python（内置环境 + xtquant 库） | Python（API 风格与聚宽相近） |
| **新手友好度** | ⭐⭐⭐⭐⭐ 零安装、文档全中文 | ⭐⭐⭐ 装置环节多 | ⭐⭐⭐⭐ 相对轻量 |
| **数据** | 平台内置，免费够学 | 内置行情，**需先下载历史数据** | 平台内置 |
| **本书衔接** | 第 8 章第一个回测的直接舞台 | 第四篇工程内容的远期舞台 | 同左 |

## 新手默认路线

1. **第一站：聚宽**——把全部注意力放在「策略逻辑 + 回测方法」上，平台复杂度最低
2. **第二站（可选）**：等你确认自己会长期玩，再去开通 QMT 或 Ptrade——开通前先读完[第 5 章 · 边界与红线](/book/part1/ch5)
3. **永远不要**：为了"平台高级"而跳过基础。平台只是舞台，策略思维才是演员
