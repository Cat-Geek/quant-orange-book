平台手册：选对你的第一站 ​

🎯 这一板块的承诺：看完一个平台页，你就能在那个平台上完成「注册 → 装好 → 跑通第一个回测」。不贩卖焦虑，只给动线。

三分钟选型 ​

💡 一句话决策

怕麻烦、想立刻动手 → 聚宽（在线平台，浏览器里写代码跑回测，零安装） 想要本地环境、为以后实盘铺路 → QMT / Ptrade（本地终端，需在支持券商开通）

聚宽 JoinQuantQMT（迅投）Ptrade（恒生）
形态在线平台，浏览器即用本地客户端（Windows）券商提供的本地/界面化终端
怎么获得官网注册即用指定券商开通（常附资金/申请门槛）指定券商开通
编程语言Python（内置环境）Python（内置环境 + xtquant 库）Python（API 风格与聚宽相近）
新手友好度⭐⭐⭐⭐⭐ 零安装、文档全中文⭐⭐⭐ 装置环节多⭐⭐⭐⭐ 相对轻量
数据平台内置，免费够学内置行情，需先下载历史数据平台内置
本书衔接第 8 章第一个回测的直接舞台第四篇工程内容的远期舞台同左

新手默认路线 ​

  1. 第一站：聚宽——把全部注意力放在「策略逻辑 + 回测方法」上，平台复杂度最低
  2. 第二站（可选）：等你确认自己会长期玩，再去开通 QMT 或 Ptrade——开通前先读完第 5 章 · 边界与红线
  3. 永远不要：为了"平台高级"而跳过基础。平台只是舞台，策略思维才是演员

三页动线（每页结构一致） ​

页你将完成
P1 · 聚宽上手注册 → 认识界面 → 跑通第一个真实回测 ✅ 全量
P2 · QMT/miniQMT 上手开通 → 安装 → xtquant 拉第一份数据 → 跑通第一个策略
P3 · Ptrade 上手开通 → 环境初体验 → 跑通第一个策略

🚨 平台手册的边界

本板块只讲学习与回测用法。实盘接入、模拟盘转实盘属于进阶内容，本书当前版本不涉及——先把回测做诚实，再谈别的。
