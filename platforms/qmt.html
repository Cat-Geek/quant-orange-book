1. QMT 是什么，和 miniQMT 什么关系 ​

QMT（迅投极速策略交易系统）是一个装在自己 Windows 电脑上的量化终端，由合作券商提供。一句话分清两兄弟：

  • QMT：完整量化终端——策略编写、回测、实盘都在这个图形界面里
  • miniQMT：轻量独立交易端——本身不写策略，但它开放了 xtquant Python 库，让你在自己喜欢的编辑器里写代码、连它的行情和交易通道

💡 人话翻译

QMT = 一体机的考场；miniQMT = 只借你考卷和答题卡，答题在自己家（你的 Python 环境）进行。新手先认识 QMT 本体即可。

2. 开通与安装动线 ​

  1. 确认资格：QMT 由券商提供，各家的开通条件不同（常见与资金量或申请挂钩）。开通前先读第 5 章 · 边界与红线，并把"只用于学习与回测"作为当前阶段的自我定位
  2. 联系券商：让客户经理开通 QMT 权限，拿到安装包
  3. 安装登录：Windows 电脑安装 → 用券商账号登录
  4. 下载历史数据（新手第一个坎，见下方坑位 1）

3. 第一个动作：用 xtquant 拉一份数据 ​

QMT 本体的策略编写在图形界面里进行；而 miniQMT 模式下，用 xtquant 库在自己电脑的 Python 里取数：

python
from xtquant import xtdata

# 下载平安银行的日K历史数据（必须先下载，本地才有）
xtdata.download_history_data('000001.SZ', period='1d', start_time='20200101')

# 读取刚下载的数据
data = xtdata.get_market_data_ex([], ['000001.SZ'], period='1d',
                                  start_time='20240101', end_time='20241231')
print(data['000001.SZ'].tail())   # 看看最后几行

能打印出 K 线数据，你的本地量化环境就算通了——这是 QMT 版的"第 7 章时刻"。

4. 新手三大卡点 ​

⚠️ 坑位 1：历史数据不会自动有

QMT 的行情数据需要手动下载（界面操作或 download_history_data）。没下载就取数，拿到的是空的——新手以为"代码错了"，其实只是数据没到位。

⚠️ 坑位 2：内置 Python 环境是"定制的"

QMT 内置特定版本的 Python 环境，和你电脑上装的 Python 不是一回事。第三方库的支持范围有限，装库方式和普通环境不同。别把在外面调试好的代码直接假设它能跑。

⚠️ 坑位 3：股票代码后缀不同

QMT 用 .SZ / .SH 后缀（如 000001.SZ），聚宽用 .XSHE / .XSHG。跨平台抄代码时后缀必改，这是 AI 生成代码的高频翻车点（API 幻觉的表亲）。

5. 你现在需要它吗？ ​

💡 诚实的建议

如果你还处在第二篇（筑基）阶段：不需要。聚宽足以完成全部学习；QMT 的价值在本地化工程与（远期的）实盘衔接。别为了"装备感"提前进入复杂度。
